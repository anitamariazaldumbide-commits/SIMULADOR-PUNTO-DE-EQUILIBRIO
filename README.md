# SIMULADOR-PUNTO-DE-EQUILIBRIO
Como parte de la propuesta pedagógica, se diseñó un simulador interactivo del punto de equilibrio, desarrollado en formato HTML, que permite a los estudiantes experimentar con los costos fijos, costos variables unitarios y precios de venta de un emprendimiento.  El recurso incorpora la fórmula del punto de equilibrio y su aplicación
